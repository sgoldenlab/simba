Research Resource Identifier (RRID)
-----------------------------------

If your journal asks for RRIDs (Research Resource Identifiers), SimBA's is
`RRID:SCR_021413 <https://scicrunch.org/resolver/RRID:SCR_021413>`__. Add it where you name SimBA in your methods,
for example: *behavior was classified using SimBA (RRID:SCR_021413)*, and cite the paper above as well.
